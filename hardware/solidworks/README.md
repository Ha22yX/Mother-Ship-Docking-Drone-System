# SolidWorks CAD Drawings

This folder contains the original SolidWorks drawings created during the Mother-Ship Docking Drone System hardware development.

Included files cover the drone platform, landing/docking frame, battery bay, GPS mounts, tube clamps, electromagnet connectors, motor/propeller reference parts, and related hardware pieces.

These files are provided as project source materials for documentation and future iteration. They are not manufacturing-ready release packages; check dimensions, materials, fasteners, and safety constraints before building from them.

## 中文说明

本文件夹保存 Mother-Ship Docking Drone System 硬件开发期间绘制的原始 SolidWorks 图纸。

内容包括无人机平台、起落/对接框架、电池仓、GPS 支架、管夹、电磁铁连接件、电机/螺旋桨参考件等硬件部件。

这些文件作为项目源材料和后续迭代参考提供，并不是可直接量产的制造发布包。实际加工前请重新检查尺寸、材料、紧固件和安全约束。
